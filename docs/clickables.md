# 可点击项

可点击项是指任何你可以点击以产生效果的东西。它们是可购买项（Buyables）的更通用版本。

**不要用这些来制作需要反复点击以获得奖励的东西，因为那种体验很糟糕。**

两者之间存在若干差异。其一，可购买项的存档数据是其数量，以 `Decimal` 形式存储；而可点击项存储的是“状态”，可以是数字或字符串，但不能是 `Decimal`、数组或对象。可购买项拥有许多额外功能，你可以在其页面上查看。可点击项的默认尺寸也较小。

用于处理可点击项及实现其效果的有用函数：

- getClickableState(layer, id)：获取玩家所拥有的可点击项的状态
- setClickableState(layer, id, state)：设置玩家所拥有的可点击项的状态
- clickableEffect(layer, id)：返回该可点击项的当前效果（如果有的话）。

可点击项的格式应如下所示：

```js
clickables: {
    11: {
        display() {return "Blah"},
        etc
    }
    etc
}
```

功能特性：

- title：**可选**。以较大字体显示在顶部。也可以是返回更新文本的函数。

- effect()：**可选**。一个计算并返回该可点击项当前加成值的函数。可以返回一个值或一个包含多个值的对象。

- display()：一个返回在标题之后应显示在可点击项上的所有内容的函数，通常会根据其状态而变化。可以使用基本 HTML。

- unlocked()：**可选**。一个返回布尔值的函数，用于确定该可点击项是否可见。默认为已解锁。

- canClick()：一个返回布尔值的函数，用于确定你是否可以点击该可点击项。

- onClick()：一个实现点击该可点击项操作的函数。

- onHold()：**可选**。当按钮被按住至少 0.25 秒时，以每秒 20 次的频率调用的函数。

- style：**可选**。以对象形式向该可点击项应用 CSS，其中键为 CSS 属性，值为这些属性的值（均为字符串）。

- marked：**可选**。在该可点击项的角落添加一个标记。如果为“true”，则显示为星形，但也可以是图片 URL。

- tooltip：**可选**。为该可点击项添加一个悬停提示，当鼠标悬停在其上时出现。可以使用基本 HTML。默认为无提示。如果此函数返回空值，也会禁用提示。

- layer：**自动分配**。与当前层名称相同，因此你可以使用 `player[this.layer].points` 或类似操作。

- id：**自动分配**。即该可点击项存储时所用的“键”，便于访问。示例中可点击项的 id 为 11。

你还可以在可点击项对象上使用以下功能，在所有可点击项上方添加一个按钮，用于实现重置技能按钮或类似功能。

- masterButtonPress()：**可选**。如果存在，将在可点击项上方显示一个额外按钮。按下该按钮将调用此函数。

- masterButtonText：**可选**。主按钮上显示的文本。

- showMasterButton()：**可选**。一个函数，用于确定是否显示该按钮（如果已定义 masterButtonPress）。若缺失，则默认为 true。

- branches：**可选**，主要用于可点击项树。一个可点击项 id 数组。从该可点击项到列表中的所有可点击项之间将绘制一条连线。或者，数组中的条目可以是一个由可点击项 id 和颜色值组成的双元素数组。颜色值可以是包含十六进制颜色代码的字符串，也可以是 1-3 的数字（受主题影响的颜色）。数组中的第三个元素可选地指定线宽。
