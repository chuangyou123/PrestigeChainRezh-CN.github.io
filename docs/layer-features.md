# 层特性

这是一个更全面的列表，列出了可以添加到层中的既有功能。如果你希望你的层具有其他功能或数值，也可以自由添加更多。不过，这些功能具有特殊作用。

你可以通过使用函数来使几乎任何值变得动态化，包括所有显示字符串和样式/颜色功能。

## 层定义功能

- layer：**自动分配**。它与该层的名称相同，因此你可以使用 `player[this.layer].points` 或类似方式访问保存的值。这使得将代码复制到新层更加容易。它也会分配给所有升级、可购买物等。

- name：**可选**。用于重置确认（以及默认信息框标题）。如果不存在，则使用层的id。

- startData()：一个返回该层默认存档数据的函数。将你拥有的任何变量添加到其中。确保使用 `Decimal` 值而不是普通数字。

    标准值：
        - 必需：
            - unlocked：一个布尔值，决定该层是否已解锁
            - points：一个 Decimal，是该层的主要货币
        - 可选：
            - total：一个 Decimal，追踪主要声望货币的总量。始终被追踪，但只有你在此添加时才会显示。
            - best：一个 Decimal，追踪主要声望货币的最高数量。始终被追踪，但只有你在此添加时才会显示。
            - unlockOrder：用于跟踪在此层之前解锁的相关层。
            - resetTime：一个数字，表示自该层上次声望重置（或被其他层重置）以来的时间。

- color：与该层关联的颜色，在许多地方使用。（十六进制格式的字符串，带有#）

- row：该层的行，从0开始。这影响节点在标准树上的位置，以及哪些重置会影响该层。

    使用"side"而不是数字将使该层作为较小的节点出现在侧面（适用于成就和统计）。侧层不受重置影响，除非你为它们添加了 doReset。

- displayRow：**覆盖** 更改层节点的显示位置，而不改变其在重置顺序中的位置。

- resource：通过重置该层获得的主要货币名称。

- effect()：**可选**。一个计算并返回主要货币固有任何加成当前值的函数。可以返回一个值或包含多个值的对象。*你还必须在应用效果的地方实现它。*

- effectDescription：**可选**。一个返回此效果描述的函数。如果文本保持不变，它可以只是一个字符串。

- layerShown()：**可选**，一个返回布尔值的函数，决定该层的节点是否应在树上可见。它也可以返回"ghost"，这将隐藏该层，但其节点仍会占据树上的空间。
    默认为 true。

- hotkeys：**可选**。一个包含与该层关联的任何快捷键信息的数组：

    ```js
    hotkeys: [
        {
            key: "p", // 快捷键按钮是什么。如果与shift组合使用则用大写，或者使用"ctrl+x"表示按住ctrl。
            description: "p: 重置你的点数以获得声望点数", // 游戏中“如何游玩”选项卡中显示的快捷键描述
            onPress() { if (player.p.unlocked) doReset("p") },
            unlocked() {return hasMilestone('p', 3)} // 决定你是否可以使用该快捷键，可选
        }
    ]
    ```

- style：**可选**。一个“CSS对象”，其中键是CSS属性，包含任何应影响该层整个选项卡的CSS。

- tabFormat：**可选**。如果你想向选项卡添加额外内容或更改布局，请使用此选项。[更多信息请参见此处。](custom-tab-layouts.md)

- midsection：**可选**，`tabFormat` 的替代方案，插入到标准选项卡布局中的里程碑和可购买物之间。（不能使用子选项卡）

## 主要功能（均为可选）

- upgrades：一组一次性购买，可以具有独特的升级条件、货币成本和加成。[更多信息请参见此处。](upgrades.md)

- milestones：达到某个资源的特定阈值后获得的加成列表。常用于自动化/生活质量改进。[更多信息请参见此处。](milestones.md)

- challenges：玩家可以进入挑战，使游戏更难。如果他们达到目标并击败挑战，他们将获得加成。[更多信息请参见此处。](challenges.md)

- buyables：实际上是可多次购买且可选重置的升级。用途广泛。[更多信息请参见此处。](buyables.md)

- clickables：极其通用和泛化的按钮，只能在某些时候点击。[更多信息请参见此处。](clickables.md)

- microtabs：一个功能类似于一组子选项卡的区域，顶部有按钮更改其中的内容。（高级）[更多信息请参见此处。](subtabs-and-microtabs.md)

- bars：将某些信息显示为进度条、仪表或类似形式。它们高度可定制，也可以垂直显示。[更多信息请参见此处。](bars.md)

- achievements：类似于里程碑，但具有不同的显示样式和一些其他差异。更多功能将在未来推出！[更多信息请参见此处。](achievements.md)

- achievementPopups, milestonePopups：**可选**，如果为 false，则获得成就/里程碑时禁用弹出消息。默认为 true。

- infoboxes：在可以显示或隐藏的框中显示一些文本。[更多信息请参见此处。](infoboxes.md)

- grid：一个按钮网格，它们的行为相同，但具有各自的数据。[更多信息请参见此处。](grids.md)

## 声望公式功能

- type：**可选**。决定你使用哪个声望公式。默认为"none"。

    - "normal"：你获得的货币数量与其当前数量无关（如声望）。加成前的公式基于 `baseResource^exponent`
    - "static"：成本取决于你重置后的总量。加成前的公式基于 `base^(x^exponent)`
    - "custom"：你可以自己定义一切，从计算到按钮上的文本。（请参见底部更多信息）
    - "none"：该层不进行声望重置，因此不需要本节中的任何其他功能。

- baseResource：决定你在重置时获得多少主要货币的资源名称。

- baseAmount()：一个获取基础资源当前值的函数。

- requires：一个 Decimal，获得1个声望货币所需的基础数量。也是解锁该层所需的数量。你也可以将此设为函数，以使其在另一个层先解锁时更难（基于unlockOrder）。

- exponent：如上所述使用。

- base：**有时必需**。“static”层需要，如上所述使用。如果不存在，默认为2。必须大于1。

- roundUpCost：**可选**。一个布尔值，如果资源成本需要向上取整则为 true。（如果基础资源是“static”货币，请使用。）

- gainMult(), gainExp()：**可选**。对于普通层，这些函数计算来自升级和加成等的资源获取的乘数和指数。在此处插入大多数加成。
    对于静态层，它们改为乘以和开根资源成本。（因此要获得加成，你想让 gainMult 更小，gainExp 更大。）

- directMult()：**可选**。在指数和软上限之后直接乘以资源获取。对于静态层，实际上乘以资源获取而不是降低成本。

- softcap, softcapPower：**可选**。对于普通层，超过 [softcap] 点的获取量被取 [softcapPower] 次方。
    softcap 的默认值为 e1e7，power 的默认值为 0.5。

## 其他声望相关功能

- canBuyMax()：**有时必需**。“static”层需要，用于确定是否允许购买最大值的函数。

- onPrestige(gain)：**可选**。当该层进行声望重置时触发的函数，就在你获得货币之前。可用于在声望时获得次要资源，或重新计算事物等。

- resetDescription：**可选**。使用此选项将声望按钮上的“重置以获取”替换为其他内容。

- prestigeButtonText()：**有时必需**。使用此选项使声望按钮包含的文本完全自定义。仅自定义层必需，但所有类型均可使用。

- passiveGeneration()：**可选**，返回一个普通数字。你每秒自动生成你的获取量乘以该数字（如果不存在则无效）。
        这对于自动化普通层很好。

- autoPrestige()：**可选**，返回一个布尔值，如果为 true，该层将始终在可能时自动进行声望重置。
        这对于自动化静态层很好。

## 树/节点功能

- symbol：**可选**。显示在该层节点上的文本。默认为层id首字母大写。

- image：**覆盖**。节点上显示的图片的URL（本地或全局）。（覆盖symbol）

- position：**可选**。决定该层在标准树中其行内的水平位置。默认使用层id，层按字母顺序排序。

- branches：**可选**。一个层/节点id数组。在树上，将出现一条从该层到列表中所有层的线。或者，数组中的条目可以是一个由层id和颜色值组成的2元素数组。颜色值可以是带有十六进制颜色代码的字符串，或1-3的数字（受主题影响的颜色）。数组中的第三个元素可选地指定线宽。

- nodeStyle：**可选**。一个CSS对象，其中键是CSS属性，用于样式化该层在树上的节点。

- tooltip() / tooltipLocked()：**可选**。返回文本的函数，分别是该层解锁或锁定时节点的工具提示。默认情况下，工具提示行为与原始声望树相同。
    如果值为""，则禁用工具提示。

- marked：**可选** 在节点角落添加标记。如果为"true"则为星形，但也可以是图片URL。

## 其他功能

- doReset(resettingLayer)：**可选**。当行号大于或等于该层的层进行重置时触发。默认行为是重置该行上的所有内容，但仅当由更高行的层触发时。`doReset` 总是为侧层调用，但对于这些层，默认行为是什么都不重置。
                
    如果你想保留某些内容，请根据 `resettingLayer`、`milestones` 等确定要保留的内容，然后调用 `layerDataReset(layer, keep)`，其中 `layer` 是该层，`keep` 是要保留的项目名称数组。它可以包括"points"、"best"、"total"（该层的声望货币）、"upgrades"、任何唯一变量如"generatorPower"等。如果你想只保留特定的升级或类似内容，请将它们保存在单独的变量中，然后调用 `layerDataReset`，然后将 `player[this.layer].upgrades` 设置为保存的升级。

- update(diff)：**可选**。此函数在每个游戏刻调用。用于任何被动资源生产或基于时间的操作。`diff` 是自上次刻以来的时间。

- autoUpgrade：**可选**，一个布尔值，如果为 true，游戏将每刻尝试购买该层的升级。默认为 false。

- automate()：**可选**。此函数在每个游戏刻调用，在生产之后。用于激活其他方式不支持的自动化操作。

- resetsNothing：**可选**。如果该层在声望时不应触发任何重置，则返回 true。

- increaseUnlockOrder：**可选**。一个层id数组。当该层首次解锁时，此列表中任何尚未解锁的层的 `unlockOrder` 值会增加。这可用于使它们更难解锁。

- shouldNotify：**可选**。一个函数，如果该层应在树中高亮显示则返回 true。无论你是否拥有此功能，如果你可以购买升级，该层将自动高亮显示。

- glowColor：**可选**。如果该层应通知，则高亮显示的颜色。默认为红色。如果你想有几种不同的通知类型，可以使用此选项！

- componentStyles：**可选**。一个对象，包含一组返回CSS对象的函数。每个都将应用于该层上具有其id类型的任何组件。示例：

```js
componentStyles: {
    "challenge"() { return {'height': '200px'} },
    "prestige-button"() { return {'color': '#AA66AA'} }
}
```

- leftTab：**可选**，如果为 true，该层将使用左侧选项卡而不是右侧选项卡。

- previousTab：**可选**，一个层的id。如果层有 previousTab，则该层将始终有一个返回箭头，按下此层上的返回箭头将带你到具有此id的层。

- deactivated：**可选**，如果为 true，hasUpgrade、hasChallenge、hasAchievement 和 hasMilestone 将对该层中的内容返回 false，并且你将无法购买或点击内容，或在该层获得成就/里程碑。你将需要自行禁用可购买物的效果、固有层效果，以及可能的其他内容。

## 自定义声望类型  
（这些也可以被其他声望类型使用）

- getResetGain()：**主要用于自定义声望类型**。返回如果你现在重置应获得多少点数。你可以调用 `getResetGain(this.layer, useType = "static")` 或类似方式来计算你在另一种声望类型下的获取量（前提是你拥有该层中所有必需的功能）。

- getNextAt(canMax=false)：**主要用于自定义声望类型**。返回你需要多少基础货币才能达到下一点。`canMax` 是一个可选变量，用于类似静态的层，以区分它是在寻找你可以重置的第一个点，还是任何获取的要求（同时支持两者是好的）。你也可以调用 `getNextAt(this.layer, canMax=false, useType = "static")` 或类似方式来计算你在另一种声望类型下的下一个点（前提是你拥有该层中所有必需的功能）。

- canReset()：**主要用于自定义声望类型**。仅当你拥有在此进行声望所需的资源时才返回 true。

- prestigeNotify()：**主要用于自定义声望类型**，如果该层应被微妙地高亮以指示你可以进行有意义的声望获取，则返回 true。
